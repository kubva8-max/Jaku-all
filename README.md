# Jaku – launcher a mody pro Minecraft

Soubory ke stažení jsou v sekci **[Releases](../../releases)**. Web: https://www.jakubestie.cz/mods/ · YouTube: https://www.youtube.com/@JakuBestie

## Jaku Launcher 2.11.0
- `Jaku-Launcher-2.11.0.zip` – Linux (spusť `jaku-launcher.sh`, sám se nainstaluje)
- `Jaku-Launcher-Windows-2.11.0.zip` – Windows (`Jaku-Launcher.exe`; SmartScreen: Další informace → Přesto spustit)

Instance, všechny verze MC, Fabric/Quilt/Forge/NeoForge, mody a modpacky z Modrinthu i CurseForge, shadery, servery, vlastní server, Party, kosmetika, čeština i angličtina.
⚠️ Offline režim je jen pro majitele Minecraftu. Online hraní přes převzetí účtu z Prism Launcheru.

## Jaku mody (Fabric, Minecraft 1.21.11, 26.1, 26.2, 26.3)
| Soubor | Co to je |
|---|---|
| `JakuBoost-1.2.0.zip` | víc FPS – culling, upscaling, předvolby PvP / Survival / Notebook (F7) |
| `JakuClient-1.1.0.zip` | PvP HUD – FPS, CPS, keystrokes, combo, reach, zoom, fullbright (pravý Shift) |
| `JakuSUPER-1.0.0.zip` | boj mód – při souboji odemkne FPS a víc cullí (F6) |
| `JakuCosmetics-1.1.0.zip` | pláště, klobouky, křídla a stopy (O) – vidíš jen ty |
| `JakuVisuals-1.0.0.zip` | PvP vzhled – nízký oheň, malý totem, obrys bloku, barva zásahu, ruka (J) |
| `JakuGuns-1.0.0-1.21.11-26.3.zip` | mušketa s dalekohledem a bajonetem – musí ho mít i server |
| `JakuDuels-1.1.1.zip` | PvP duely pro server (jen 26.3, klienti vanilla) |
| `Jaku-Client-1.3.0-<verze>-modpack.zip` | balíček pro Prism Launcher – všechny Jaku mody + Sodium, Iris, shadery |
| `JakuShade-*.zip` | shadery pro Iris (Pro, RT, Reflect, Lite) |

Každý zip obsahuje `NAVOD.txt`. Mody potřebují Fabric Loader a Fabric API.
